## 这是什么

股票中台的面板前端。

**只包含界面，不包含选股策略和打分引擎。**

## 为什么只开前端

选股逻辑是个人资产，开出去等于公开自己的交易思路，也会引来一堆「按你这个策略怎么亏了」的麻烦。

界面不一样：信息架构、卡片布局、视觉语言这些东西，分享出去不会伤害任何人，还能帮到想做类似工具的人。

## 界面结构

六张卡：

| 卡 | 内容 |
|---|---|
| 行情总览 | 主要指数与自选股涨跌 |
| 持仓 | 成本、现价、盈亏、仓位占比 |
| 信号 | 触发的条件与时间 |
| 情绪与轮动 | 板块热度与资金流向 |
| 待办 | 需要人工判断的事项 |
| 系统状态 | 数据更新时间与来源 |

设计原则：**数字配趋势**。单个数字没有意义，要能一眼看出涨跌方向与幅度。

## 用法

直接双击 `index.html`，或：

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

页面内是演示数据，接自己的数据源需要改 JS 里的数据入口。
